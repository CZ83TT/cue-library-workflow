# 音乐库整理约定

## 目录命名

优先使用：

```text
艺术家 - 专辑
艺术家 - 专辑 [版本]
艺术家 - 专辑 CD1
艺术家 - 专辑 CD2
```

删除下载来源、分享站标记、重复的 `[WAV+CUE]` 和无助于识别版本的宣传文字。版本信息确实能区分发行版时保留，例如 `XRCD`、`K2HD`、`HQCD`、`黑胶版` 或 `现场版`。

## 音频文件命名

分轨文件统一使用：

```text
01 - 曲名.wav
02 - 曲名.wav
```

序号只用于文件排序和 `TRACK` 字段。歌曲标题本身不要重复带序号，也不要把歌手拼进标题。

## CUE 字段

```cue
PERFORMER "艺术家"
TITLE "专辑"
FILE "01 - 曲名.wav" WAVE
  TRACK 01 AUDIO
    TITLE "曲名"
    PERFORMER "艺术家"
    INDEX 01 00:00:00
```

整轨文件保留原始 `INDEX` 时间；每首独立音频文件的 CUE 才使用每首文件从 `00:00:00` 开始的结构。

## 标签字段

建议至少统一：

- `TITLE`：不带序号的歌曲名
- `ARTIST`：实际演唱者；合唱者可使用多值标签
- `ALBUM`：同一张专辑的统一名称
- `ALBUMARTIST`：专辑主艺术家或“群星”
- `TRACKNUMBER`：`01/12` 形式
- `DATE`：只有版本信息得到证据支持时才写入

## 发布前检查

- CUE 为 UTF-8，中文没有乱码或替换字符。
- 每个 `FILE` 引用都指向同目录的真实音频文件。
- `TRACK` 编号连续，未意外改变整轨 `INDEX` 时间。
- CUE 的 `TITLE` 和 `PERFORMER` 分开，不能把歌手拼在曲名中。
- 没有把整轨音频和 CUE 同时加入 Foobar2000。
- 缺失音频、版本冲突和网上歌单差异均有明确记录。
